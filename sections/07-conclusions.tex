\section{Conclusions}
\label{sec:conclusions}

This paper introduced a semantics-based approach that transforms
conventional unit tests into property-based tests,
implemented in our Java prototype \ToolTeralizer{} for pure methods
over primitive and boxed scalars and restricted string operations.
The approach extracts path-specific input/output specifications through single-path symbolic analysis,
generates inputs that satisfy the extracted constraints,
and retains the original assertions with expected values replaced by symbolic output expressions.
This makes test generalization complementary to test generation.
It retains the assertions of existing tests
and extends each check to the input partition of its execution path.

The evaluation shows both the reach and the limits of this approach.
On the 12 projects from JARVIS's original evaluation,
\ToolTeralizer{} produces generalized tests for 9 projects,
whereas JARVIS reports success for 2.
Under controlled conditions, generalization improves mutation scores
by 1--4 percentage points on generated test suites.
Pareto analysis also shows that short test generation followed by generalization
can outperform longer test generation alone.
For mature developer-written Apache Commons tests,
the improvement is only 0.05--0.07 percentage points,
which indicates limited remaining opportunity for the evaluated mutation operators.
Under real-world conditions, \TzRealworldApplicabilityProjects{} of
\TzRealworldEligibleProjects{} eligible RepoReapers projects complete all five stages,
yielding \TzRealworldGeneralizationsFinalUsable{} generalized tests that pass through mutation testing.
The exclusions expose three broad barriers:
prototype and project-integration limitations,
insufficient path evidence for sound generalized oracles,
and build, execution, or environment failures.

Advancing semantics-based test generalization therefore requires
both broader implementation support and research on specification extraction,
encoding, and understandable generated tests.
Our open implementation and replication package~\cite{replicationpackage}
support reproduction of the reported results and further work on these challenges.
