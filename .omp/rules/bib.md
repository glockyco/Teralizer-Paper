# main.bib conventions

- Name keys `author_year_keyword`, with the first author's surname in lowercase, the four-digit year and one keyword. Rename an existing key only together with every `\cite{...}` that uses it.
- Format every entry with title case, brace-protected acronyms, expanded venue names, lowercase DOIs and en-dash page ranges, and remove DBLP-specific fields.
- Find a paper, retrieve it and verify its metadata with `skill://research-evidence`.
